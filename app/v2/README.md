CMSD Virtual Piano Duet — Melody Notebook v2

Separate route: https://apps.musedlab.org/virtualduet/cmsd/v2/
The original /cmsd/ remains unchanged.

Capture engine provenance: ruthmann/rengongfu-sandbox, local recovered revision
fc87b1276ad1a9f6eb650455bb03059ee9341793, assets/js/takes.mjs and
 tools/scale-rows/index.html. This reuses its gesture recorder, timestamped event
format, piano-roll renderer and timed player. Workshop defaults are retained:
2.5-second released-key gap, minimum two notes / 800 ms, 90-second maximum,
newest 60 takes, local browser storage and JSON export/import.

Adaptations: independent CMSD storage namespace; explicit unavailable-storage
feedback and in-memory fallback; schema validation; enforced maximum timer;
source-key tokens preserve overlapping same-pitch inputs; CMSD note labels,
colors and accessible collapsible tray. Replay bypasses capture and uses the
same piano samples. Replay can be heard alone or synchronized to the saved
performance video's starting point. Recording stores note events, not microphone
or video audio. No new backend or user tracking is introduced.

The capture adapter wraps the tested 291ad08 original duet's DOM note-on/off
methods. This preserves key mappings, repeat handling, natural audio ringout,
Makey focus controls and keyboard form exclusions. V2 index uses a parent base
URL so media remain shared; the deployment build pins parent JS/CSS dependencies
to their existing 291ad08 versioned names. Only v2 files are published.

The browser fixture isolates localStorage in memory, then checks actual Web Audio
waveforms and captured event streams as well as the UI. These are simulated
browser key/touch tests; physical Makey Makey and phone/tablet devices require
separate hardware testing.

Return from replay: Stop and Play along resume the duet and return focus to the
piano. Collapsing during replay also returns to live duet playing. With-duet
playback leaves the background running when the saved phrase finishes.

Welcome controls: Makey Makey and English/Chinese choices live together inside
the opening/help panel; the piano surface retains only the question-mark help
button. The controls share Montserrat and the panel's indigo palette. Makey
changes keep focus in the open panel; starting the duet still restores piano
focus. The language module is recovered from the deployed 20261015 module,
with the existing storage key and embedding protocol retained. Its dictionary
also recognizes the actual uppercase ON label generated by the input handler.

The current hosted entry has later consent, language and pinned dependencies
not yet fully reconciled into this repository. Publish this change as a narrow
overlay on that current entry, retaining every unchanged live dependency.
Do not replace the hosted entry wholesale with this source wrapper.

Mobile layout: one complete melody per page on compact/touch displays, with
previous/next controls and all melodies retained in export/import. Short landscape
puts the notebook beside the video. Safe-area padding and visualViewport height
keep controls within the visible screen. Rotation preserves playback state; the
video and transparent keys share the same contain-fit rectangle. Makey Makey is
hidden on touch displays. Privacy preferences reuse the existing shared consent
button inside welcome/help; no consent or analytics implementation is changed.

Mobile fixture: serve the repository as above, open
/test/cmsd-mobile.html?touch=1&lang=en and click Run mobile checks after samples
load. F8 simulates safe-area insets; F9 records geometry in #layoutReport.
Use lang=zh for Chinese. Fixture storage is temporary and Google is intercepted.
The consent fixture is pinned to the existing access-r2-20261020 integration.
